Types of OpenMP tasks www.sbenedictglobal.com Types of OpenMP tasks Undeferred OpenMP task Deferred Meaning – Postposed or Delayed or Suspended Task creations are not deferred (task creations are not delayed). i.e., tasks are created and moved to the conceptual pool for future executions. Hence, the undeferred tasks might not be executed immediately by the encountering thread. The task might be generated by one thread and got executed by some other thread. Included OpenMP Task an included task is executed immediately by the encountering thread and is not placed in the pool to be executed at a later time. the generation of the tasks is suspended until the execution of the included task is completed. Only after the execution step, the generating task can resume. Merged OpenMP Tasks A merged task is a task whose data environment is the same as that of its generating task region. If a merged task is generated, the behavior is equivalent to the normal execution of a parallel region. www.sbenedictglobal.com Dependent OpenMP task Tasks whose execution order is constrained by dependencies on other tasks.
