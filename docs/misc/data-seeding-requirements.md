# Data Seeding Requirements — IELTS Study Mentor

**To:** Data Team
**From:** Backend Engineering
**Date:** 2026-05-06
**Re:** Content seeding for `drill_questions` and `lexigrid_words` tables

---

## 1. General Instructions

- All data must be submitted as a **JSON array** (one file per table, or one combined file with two keys).
- Field names must match exactly as documented below (snake_case).
- Do **not** include `id`, `is_active`, `created_at`, or `updated_at` — these are auto-generated by the database.
- All enum values are **case-sensitive** and must be UPPER_SNAKE_CASE as listed.

---

## 2. Table: `drill_questions`

### 2.1 Schema Reference

| Field | Type | Allowed Values / Notes |
|---|---|---|
| `skill` | enum `IeltsSkillType` | `LISTENING`, `READING`, `WRITING`, `SPEAKING` |
| `sub_skill` | enum `IeltsSubSkillType` | See mapping below |
| `level` | enum `RecommendationLevel` | `BEGINNER`, `INTERMEDIATE`, `ADVANCED` |
| `drill_type` | string | Always `"MCQ"` (for this batch) |
| `prompt_text` | string | The MCQ question text |
| `options` | JSON object | Keys must be `"A"`, `"B"`, `"C"`, `"D"` with string values |
| `correct_answer` | JSON (string) | One of `"A"`, `"B"`, `"C"`, `"D"` — must be a **JSON-encoded string** e.g. `"\"C\""` |
| `explanation` | string | Brief explanation of the correct answer |

### 2.2 Skill → Sub-Skill Mapping

| Skill | Sub-Skills (one entry per sub-skill) |
|---|---|
| `WRITING` | `GRAMMAR`, `VOCABULARY`, `COHERENCE`, `TASK_RESPONSE` |
| `SPEAKING` | `GRAMMAR`, `VOCABULARY`, `FLUENCY`, `PRONUNCIATION` |
| `READING` | `READING` |
| `LISTENING` | `LISTENING` |

> [!IMPORTANT]
> Writing and Speaking each have **4 sub-skills**. Reading and Listening each have **1 sub-skill** (same name as the skill itself).

### 2.3 Volume Requirements

**20 questions per (skill × sub_skill × level) combination.**

| Skill | Sub-Skills | Levels | Questions per Set | Total |
|---|---|---|---|---|
| WRITING | 4 | 3 | 20 | **240** |
| SPEAKING | 4 | 3 | 20 | **240** |
| READING | 1 | 3 | 20 | **60** |
| LISTENING | 1 | 3 | 20 | **60** |
| **Grand Total** | | | | **600** |

> [!NOTE]
> A "set" is uniquely identified by the composite key `(skill, sub_skill, level)`. The drill engine serves questions from a set in a round-robin fashion, so 20 questions per set ensures sufficient variety.

### 2.4 JSON Format

```json
[
  {
    "skill": "SPEAKING",
    "sub_skill": "VOCABULARY",
    "level": "ADVANCED",
    "drill_type": "MCQ",
    "prompt_text": "More formal expression?",
    "options": {
      "A": "Kinda obvious",
      "B": "I reckon",
      "C": "It can be argued",
      "D": "Everyone knows"
    },
    "correct_answer": "\"C\"",
    "explanation": "Formal tone is preferred in academic and professional contexts."
  }
]
```

> [!WARNING]
> `correct_answer` must be a **JSON-encoded string** — wrap the letter in escaped double quotes: `"\"C\""`. This matches the `Json` column type in the database.

### 2.5 Content Guidelines per Level

| Level | Description |
|---|---|
| `BEGINNER` | Simple vocabulary / grammar / basic sentence structures. Band 4–5 equivalent. |
| `INTERMEDIATE` | Moderate complexity, mixed formal/informal usage. Band 5.5–6.5 equivalent. |
| `ADVANCED` | Academic or IELTS Band 7+ phrasing, nuanced grammar, complex collocations. |

## 3. Table: `lexigrid_words`

### 3.1 Schema Reference

| Field | Type | Allowed Values / Notes |
|---|---|---|
| `base_word` | string (max 100) | The simpler / common word shown to the student |
| `target_word` | string (max 100) | The IELTS-appropriate upgrade word |
| `hint` | string (text) | A definition or usage hint for the target word |
| `category` | string | `"descriptive"`, `"formal"`, `"academic"` |
| `difficulty` | string | `"BEGINNER"`, `"INTERMEDIATE"`, `"ADVANCED"` |
| `target_band` | decimal (X.0) | IELTS target band score tied to this word |

### 3.2 Difficulty → Target Band Mapping

| Difficulty | Target Band |
|---|---|
| `BEGINNER` | `5.0` |
| `INTERMEDIATE` | `6.0` or `6.5` |
| `ADVANCED` | `7.0` or higher |

> [!NOTE]
> `target_band` must be a decimal with one decimal place (e.g. `5.0`, `6.5`, `7.0`, `8.0`). Do not use integers.

### 3.3 Category Definitions

| Category | Description |
|---|---|
| `descriptive` | Words that describe qualities, emotions, or attributes vividly |
| `formal` | Words suited for formal writing and speech (replacing casual/colloquial terms) |
| `academic` | Words common in academic writing / IELTS essay contexts |

### 3.4 Volume Requirements

**25 words per difficulty level** — 75 words total.

| Difficulty | Count |
|---|---|
| `BEGINNER` | 25 |
| `INTERMEDIATE` | 25 |
| `ADVANCED` | 25 |
| **Total** | **75** |

Try to distribute evenly across all three categories within each difficulty level (~8–9 words per category per difficulty).

### 3.5 JSON Format

```json
[
  {
    "base_word": "POOR",
    "target_word": "DESTITUTE",
    "hint": "Without the basic necessities of life; in a state of extreme poverty.",
    "category": "descriptive",
    "difficulty": "INTERMEDIATE",
    "target_band": 7.0
  }
]
```
