**To:** Data Team / Content Team

---

## 1. General Instructions

- All data must be submitted as a **JSON array** (one file per sub-skill group, or one combined file).
- Field names must match exactly as documented below (snake_case).
- Do **not** include `id`, `is_active`, or `created_at` — these are auto-generated by the database.
- All enum values are **case-sensitive** and must be UPPER_SNAKE_CASE as listed.
- `correct_answer` must be a **JSON-encoded string** — wrap the value in escaped double quotes: `"\"A\""`. This matches the `JSONB` column type. For AI-analyzed questions (WRITING_PROMPT, SPEAKING_PROMPT) set `correct_answer` to `null`.

## 2. Table: `IAQuestion`

### 2.1 Schema Reference

| Field | Type | Allowed Values / Notes |
|---|---|---|
| `skill` | enum `IeltsSkillType` | `LISTENING`, `READING`, `WRITING`, `SPEAKING` |
| `sub_skill` | enum `IeltsSubSkillType` | See mapping in §2.2 |
| `question_type` | string | `"MCQ"`, `"TFNG"`, `"WRITING_PROMPT"`, `"SPEAKING_PROMPT"` |
| `passage_id` | string or null | Group ID string (e.g. `"R_BEG_P1"`) — all questions sharing one reading passage must share the same `passage_id`. Null for non-reading questions. |
| `passage_text` | string or null | Full reading passage text. Only on **one** question per passage group — all other questions in that group set `passage_text` to `null`. The engine looks up passage by `passage_id`. |
| `audio_url` | string or null | Relative path to the audio file (e.g. `"/ia/audio/listening_beg_1.mp3"`). Required for LISTENING questions. Null for all others. |
| `prompt_text` | string | The question text shown to the student |
| `options` | JSON object or null | Keys must be `"A"`, `"B"`, `"C"`, `"D"` with string values. Required for MCQ and TFNG. Null for WRITING_PROMPT and SPEAKING_PROMPT. |
| `correct_answer` | JSON string or null | One of `"\"A\""`, `"\"B\""`, `"\"C\""`, `"\"D\""` for MCQ. One of `"\"TRUE\""`, `"\"FALSE\""`, `"\"NOT GIVEN\""` for TFNG. **`null`** for WRITING_PROMPT and SPEAKING_PROMPT. |
| `explanation` | string or null | Brief explanation of why the answer is correct. Required for MCQ and TFNG. Null for AI-scored question types. |
| `difficulty` | enum `DifficultyType` | `BEGINNER`, `INTERMEDIATE`, `ADVANCED` |

### 2.2 Skill → Sub-Skill Mapping

| Skill | Sub-Skills |
|---|---|
| `WRITING` | `GRAMMAR`, `VOCABULARY`, `COHERENCE`, `TASK_RESPONSE` |
| `SPEAKING` | `GRAMMAR`, `VOCABULARY`, `FLUENCY`, `PRONUNCIATION` |

> `GRAMMAR` and `VOCABULARY` appear under **both** WRITING and SPEAKING. They are separate question sets — WRITING GRAMMAR tests written grammar rules; SPEAKING GRAMMAR tests spoken grammar awareness. Tag the `skill` field correctly.

## 3. Content Guidelines per Sub-Skill

### GRAMMAR (Writing & Speaking)
- Test a single grammar rule per question — no compound rules.
- Cover: subject-verb agreement, tense consistency, conditionals (types 1/2/3), articles (a/an/the/zero), relative clauses, passive voice, modal verbs.
- WRITING GRAMMAR: distractors should be plausible written errors (agreement, tense, articles).
- SPEAKING GRAMMAR: questions should reflect common spoken grammar errors (e.g., "I have went" vs "I went").

### VOCABULARY (Writing & Speaking)
- MCQ format: one word underlined or a blank to fill, four synonyms/options.
- Test collocations, register (formal vs informal), and word-in-context inference.
- Do not repeat the same word across difficulty levels.

### COHERENCE (Writing)
- MCQ questions: test linking words, paragraph ordering, cohesive device choice.
- WRITING_PROMPT: provide a chart/graph description or short essay task. Must be completable in 8–10 minutes.

### TASK_RESPONSE (Writing)
- MCQ questions: test awareness of task types, essay structure, on-topic vs off-topic responses.
- WRITING_PROMPT: full Task 2 opinion/discussion question. Must be a standalone prompt.

### FLUENCY (Speaking)
- MCQ questions: identify which response demonstrates better fluency, coherence, or linking.
- SPEAKING_PROMPT: open-ended Part 2-style cue card topic. Student speaks for 1–2 minutes.

### PRONUNCIATION (Speaking)
- MCQ questions: identify correct word stress, intonation pattern, or pronunciation rule.
- SPEAKING_PROMPT: describe a place, person, or experience — designed to surface common pronunciation patterns.

### READING
- Each difficulty uses one distinct passage (~200 words BEGINNER, ~300 words INTERMEDIATE, ~450 words ADVANCED).
- 5 TFNG + 5 MCQ per passage. MCQ tests inference and vocabulary-in-context.
- `passage_id` naming convention: `R_BEG_P1`, `R_INT_P1`, `R_ADV_P1`.

### LISTENING
- Each difficulty uses one distinct audio recording.
- BEGINNER: telephone conversation, form-filling context.
- INTERMEDIATE: two-person discussion, lecture extract.
- ADVANCED: academic monologue or multi-speaker debate.
- 10 MCQ questions covering detail recognition, inference, and vocabulary.
- `audio_url` naming convention: `/ia/audio/listening_beg_1.mp3`, `/ia/audio/listening_int_1.mp3`, `/ia/audio/listening_adv_1.mp3`.
